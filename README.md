# Yolcatl · landing page

Estructura
- server.js (Express + SQLite: /subscribe, /stats, /contact, /feedback) y sirve la carpeta public/
- public/index.html, styles.css, main.js, assets/

Ejecutar: npm install express sqlite3 cors  ->  node server.js  ->  http://localhost:3000
Etiquetas de canal: abrir la página con ?src=sobre_semillas, ?src=cartel_campus, ?src=tiktok, ?src=discord
